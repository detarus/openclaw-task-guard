# Release v1.0.0.0

Initial stable checkpoint for `openclaw-task-guard`.

## Included in this release

- durable task journaling for inbound task lifecycle
- stale task reconciliation (`awaiting_reply` -> `awaiting_confirmation` -> `recovery_pending`)
- recovery candidate generation and safe one-shot policy
- approval-based recovery flow
- `task-closure-guard` companion skill scaffold
- canonical restart-recovery path for guarded `gateway restart`
- automatic post-start resume-status send for the main Telegram direct chat
- documentation cleanup and operator mini-docs

## Notes

This release establishes the canonical restart-recovery path and repo structure.
General interrupted task continuation is still future work.
